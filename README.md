# Smart Timetable Generator

A web app that lets users add subjects with a day, start time, and room,
and automatically builds a weekly timetable grid styled like a station
departure board — with conflict checking so no two subjects can be
scheduled in the same day/time slot.

## Team
- Member A: Frontend (index.html, form UI, board styling)
- Member B: Backend (timetable_backend.js, slot storage, conflict checking, grid rendering)

## Tech
- HTML, CSS, JavaScript (no external libraries) — Oswald + Share Tech Mono via Google Fonts

## How to run
Open `index.html` in a browser (needs internet on first load for the fonts),
with `style.css` and `timetable_backend.js` saved in the same folder.
